## Resolutions

The pad of iteration 2 answers the last three questions, so they are now
constraints.

- **U9: runtime validation with a dedicated error.** `completion` validates
  `app_name` before any allocation and returns
  `CompletionError = std.mem.Allocator.Error || error{InvalidAppName}`. The
  accepted contract is the proposed one: non-empty, ASCII, no whitespace or
  control bytes, no `/`, no leading `-`, charset `A-Za-z0-9._+-`. Shell
  identifiers are derived by replacing every byte outside `[A-Za-z0-9_]` with
  `_`; registration keeps `app_name` verbatim and quoted. There is no empty-name
  fallback to `App.name`, and no hash suffix, so sanitization collisions
  (`a-b` / `a_b`) remain a documented limitation.
- **U10: two test surfaces.** The pure-Zig completion tests are the M19 block in
  `src/dap.zig` and run under `zig build test`. Shell integration lives only in
  `src/completion_test.zig` and runs under the dedicated
  `zig build completion-test` step, which the default `test` step does not
  depend on.
- **U11: integration depth and missing shells.** bash and fish get semantic
  checks; zsh gets a syntax check plus a sourcing smoke test, with semantic zsh
  completion left as a manual check. A missing shell is skipped with a visible
  notice rather than failing the step; CI that wants a hard guarantee installs
  all three.

No `# Critical` section was added, so nothing is outstanding beyond the pad.

## Residual risks (implementation-time, not open questions)

These are verification items, not decisions:

- bash `=` wordbreak lookahead and the `prev == '='` / `cur == '='` arms.
- zsh `compadd -d` display handling, `PREFIX` versus `IPREFIX` for
  `--long=value` candidates, and the `funcstack` guard in autoload and sourced
  modes.
- fish `commandline -opc` / `-ct` shapes at the cursor and tab-separated
  descriptions under `complete -C`.
- bash 3.2 has no `compopt`, so file fallback is registered once with
  `-o default` and cannot be disabled per call.
- Identifier collisions after sanitization for two dap CLIs in one bash or fish
  session; zsh is namespaced by the function name.
