### Registry

`commandNodes(NS)` (`src/dap.zig:2803`) is a comptime pre-order walk: the
level itself, then every command node below it, rebuilt with the same
`Sub(c.Cmd, subApp(NS.app_meta, c))` expression `View` and `CommandPayload`
use, so Zig returns the identical instantiation. `checkCommandNodes`
(`src/dap.zig:2819`) is the U2 guard, called once from the shell's `Nodes`
decl so the recursion does not re-check every subtree.

### Generic accessor

The shell (`src/dap.zig:2672-2710`) now carries:

- `const Nodes: []const type = commandNodes(@This())` after the guard;
- `fn NodeOf(comptime V: type) type`, resolving a `View` type to its node —
  `@compileError("dap.command: '<path>' declares no subcommands")` for a
  leaf, `@compileError("dap.command: argument is not a command View of
'<root>'")` for a foreign value;
- `pub fn command(view: anytype) ?NodeOf(@TypeOf(view)).CommandPayload`, the
  old body with `cmd_entries` swapped for the resolved level's `commands` and
  `CommandPayload` swapped for that level's union.

`Nodes` is lazy: it is only analysed when `command` is instantiated, and a
child shell's own `Nodes` is never read by `commandNodes`, so the recursion
terminates. `pub const CommandPayload` stays for the current level.

Both error paths were verified by temporarily compiling
`CLI.command(v._body.?._left.?)` and `CLI.command(@as(u8, 0))`: neither
compiles, and each reports the intended message.

### Syntax note

The snippet in `SUBCOMMANDS-DISPATCHER.md` is one statement short: Zig wants
a terminator on the outer `if` whose body is a `switch`, so the outer branch
needs an `else` (or a trailing `;`). Every doc example added or refreshed
uses the valid spelling with an `else`. The inner nesting itself is exactly
the requested shape.
